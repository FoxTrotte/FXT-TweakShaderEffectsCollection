# FXT-TweakShaderEffectsCollection
## A collection of Reshade, Shadertoy, and other open-source GPU effects for the TweakShader After Effects plugin.

[TweakShader](https://github.com/mobile-bungalow/tweak_shader_ae_plugin) is an Adobe After Effects plugin that allows you tu use GLSL shaders as an effect in your After Effects compositions.
This repo is a collection of the effects I have ported to work with TweakShader.
